# Midnight Rebels app

Installers for the Midnight Rebels app. No source code here.

## PC (Windows)

1. Open **Releases** on the right and download the newest `MidnightRebels-vN-Setup.exe`.
2. Run it. Windows may say "Windows protected your PC" because the app is not signed: click **More info**, then **Run anyway**.
3. That is the only manual install. From v14 on, the app updates itself: when a new version is out it downloads it, waits until nothing is exporting, gives you 15 seconds to press LATER, then closes, updates and reopens.

You can switch this off in Settings, under UPDATE BY ITSELF.

## Phone (Android)

Download `MidnightRebels-vN-arm64.apk` (most phones) or `-armv7.apk` (older phones) from the newest release and open it. Android asks you to allow installs from your browser or files app the first time. Phones do not update by themselves: install the newer APK the same way.

## Gemini

The app has no Gemini key built in. Each person pastes their own free key from aistudio.google.com/apikey in Settings, under GEMINI.
